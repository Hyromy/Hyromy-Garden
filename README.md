Sitio web busca representa mi identidad, un espacio donde pueda exhibir notas, ideas, proyectos, actividades, pensamientos impulsivos, deshacerlos y rehacerlos cuantas veces haga falta. Pueden no ser buenas ideas ni ser perfectas, pero no dejan de ser ideas y eso está bien.

Esta web expone lo que me gusta y puedo hacer, solo es un pequeño espacio, nada especial.

## Ejecutar proyecto

1. Clonar repositorio
```sh
git clone https://github.com/Hyromy/Hyromy-Garden.git # HTTPS
git clone git@github.com:Hyromy/Hyromy-Garden.git     # SSH

cd Hyromy-Garden
```

2. Instalar dependencias
```sh
pnpm i
```

3. Ejecutar entorno de desarrollo
```sh
pnpm dev
```
